# 美术资源目录（M1 起使用）

按用途分子目录，资源通过 `src/content/assets.ts` 的 id → 路径清单引用，
**代码里禁止直接写图片路径**（见 docs/adr/ADR-0005-美术资源策略.md）。

```
public/assets/
├── characters/   角色立绘（说话者头像）
├── cards/        卡面背景与插画
├── icons/        四指标图标
└── endings/      死亡结局插画
```

## 合规提醒（不变量 #8 / ADR-0006）

本目录下的蜘蛛侠相关美术**仅限本地开发与本地试玩**，
禁止进入任何可公开访问的部署产物、CDN 或分享链接。本项目定位为个人练习，不公开发布。

## 添加新资源时

1. 放到对应子目录，文件名用 kebab-case
2. 在 `src/content/assets.ts` 登记：id / 路径 / 用途 / 来源与生成日期（AI 生成需记录生成方式）
3. 资源缺失时会自动回退到程序化占位，**不会白屏**，但应及时补登记
