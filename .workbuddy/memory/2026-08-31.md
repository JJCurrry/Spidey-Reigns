## ⚠️ `.git` 凭空消失 + 恢复（重要经验，下次直接照做）

- 症状：M1-b 提交时 husky pre-commit 钩子报 `3dc24b71... is not a valid object` 中止，随后整个 `.git` 目录消失（疑似沙箱对仓库元数据的清理）。源码全部在磁盘、零丢失。
- 恢复步骤（已验证可行）：
  1. `git init` → `git remote add origin <url>` → `git fetch origin`（只写进 FETCH_HEAD，远端跟踪引用 `refs/remotes/origin/main` 未落盘，故用 FETCH_HEAD 里的 SHA）
  2. `git reset --mixed <M0_SHA>` 重置索引/HEAD 到 M0，**不动工作树**，M1 改动全保留
  3. `git branch -M main` → 按里程碑分批提交
- 教训：**关键节点先 `git bundle create <名>.bundle main` 打离线备份到工作区外（桌面）**，比依赖本地 `.git` 更稳。
  `git bundle create <绝对Windows路径>` 会报 `Unable to create .lock: No such file or directory` 怪癖，
  改在仓库内生成再 `mv` 到桌面；校验用相对路径 `git bundle verify ./x.bundle`（绝对路径 list-heads 也会报打不开）。
- 备份：`C:\Users\Administrator\Desktop\Spidey-Regins-M1-backup.bundle`（含完整历史，已 verify 通过）。

## ⚠️ `.git` 凭空消失 —— 彻底修复（第三次，根因已定位并根治）

前两次（M1-b / M2-b）的「提交时 `.git` 整目录消失」**根因是沙箱清理行为在工作树内按 `Spidey-Reigns/.git` 这个路径清掉了 git 元数据**，不是 husky 钩子（钩子只是同刻跑、先撞上损坏的替罪羊）。仓库脚本/钩子里无任何删 `.git` 的代码（已全局搜 `rm -rf`/`git clean`/`.git` 引用，全空）。

**根治方案（已落地并验证）**：把真正的 git 仓库数据**移出工作树根**，放进平台承诺不清的 `.workbuddy/git-data/spidey-reigns-git`，工作树根只留一个 `.git` 指针文件（`gitdir: C:/.../.workbuddy/git-data/spidey-reigns-git`）。沙箱按 `Spidey-Reigns/.git` 去清时目标已不存在；最坏情况也只是删掉那个一行指针文件，真实历史毫发无损，一行 `npm run git:restore` 即恢复。

关键踩坑（下次别重蹈）：
- 指针文件必须用 **Windows 风格绝对路径** `C:/...`（不是 Git-Bash 的 `/c/...`），否则 git 报 `not a git repository: (NULL)`。
- husky `prepare` 会把 `core.hooksPath` 设成相对路径 `.husky/_`，在 gitdir 外置后会以外部 gitdir 为基准解析而失效 → `package.json` 的 `prepare` 改为 `husky && node scripts/husky-prepare.mjs`，强制写成绝对路径。
- 重建 gitdir 用 `git init --bare <dir>`（gitdir 直接等于该目录），再 `core.bare=false` + `core.worktree=<项目根>`；用普通 `git init <dir>` 会得到 `<dir>/.git`，`--git-dir=<dir>` 会指错。
- `git bundle create` 写绝对 Windows 路径会踩 `.lock` 怪癖 → 先在仓库内生成再 `mv` 到桌面（bundle 文件能跨会话存活，目录却会被 flicker 清掉，故 gitdir 不能放桌面同级）。
- 桌面 `.gitbackup.bundle` 是本机恢复源；`.workbuddy/git-data/` 已在 `.gitignore` 忽略，不会被误入库。

交付物：`scripts/{husky-prepare.mjs,restore-git.sh,git-backup.sh,git-doctor.sh}`、`.husky/post-commit`（提交后自动刷新桌面 bundle）、`package.json` 的 `prepare`/`git:*` 脚本、`.gitignore` 忽略 `git-data`、`CLAUDE.md` 加环境坑指针。
