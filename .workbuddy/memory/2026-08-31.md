## 修掉的 Git 推送障碍

用户 `git commit` 报 `npx: command not found`、`git push` 报 `src refspec main does not match any`。
两个独立问题：

1. 钩子失败 → 提交没生成 → 空仓库自然无处可推。根因是 **Git 钩子不继承交互式 shell 的 PATH**。
   重写 `.husky/pre-commit`：补 PATH 候选目录 + 直接调用本地 lint-staged 入口（绕开 npx）。
   用 `env -i PATH=... sh .husky/pre-commit` 模拟受限环境实测通过。
2. `git remote add origin` 报「已存在」是正常的——远端早就配好了，不需要重加。
