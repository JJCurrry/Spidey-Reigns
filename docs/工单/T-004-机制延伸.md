## 范围边界（In scope）

### 1. 更多特殊死法（内容）
- `src/content/deaths.ts`：新增 **3 条**特殊死法（选项直接触发 `death-<id>`，优先于指标越界），与既有 `death-exhausted-vow` / `death-unmasked` / `death-hero-falls` 同机制。
  - `death-traded-places`「交换」：替他人挡下致命一击。
  - `death-last-swing`「最后一荡」：力竭前送走最后一人后松手。
  - `death-public-shame`「全民围观」：摘下面具求援却被镜头消费。
- 每条特殊死法必须被至少一张卡引用（由 content 守卫「选项引用结局必须存在」+ 本单新增「特殊死法可达」断言共同保证）。

### 2. flag 链剧情延伸（内容）
- `src/content/cards.ts`：新增 **6 张**条件 / flag / `once` 卡，延伸既有链并开新线：
  - **MJ（米歇尔·琼斯）私人线**：`card-mj-rooftop`（设 `flag-mj-knows`）→ `card-mj-choice`（条件 `flag-mj-knows`，左分支触发 `death-public-shame`）。
  - **毒液链延伸**：`card-venom-legacy`（条件 `flag-has-venom`）。
  - **绿魔链收尾**：`card-goblin-echo`（条件 `flag-goblin-final`）。
  - **英勇牺牲线**：`card-traded-hero`（条件 `life ≤ 30`，左分支触发 `death-traded-places`）、`card-last-swing`（条件 `life ≤ 20`，左分支触发 `death-last-swing`）。
- `src/content/unlocks.ts`：把上述新卡归入档位（每张恰属一档；tier-0 保持含 `card-quiet-night` 且非空）。
  - tier-1：`card-mj-rooftop` / `card-traded-hero` / `card-last-swing`
  - tier-2：`card-mj-choice` / `card-venom-legacy`
  - tier-3：`card-goblin-echo`

### 3. 成就 / 结局图鉴页（UI + 纯函数）
- `src/content/achievements.ts`：纯函数 `achievementsFor(save: SaveData): readonly Achievement[]`，从存档（已见死法 / 已玩局数 / 最短回合）派生一组成就，不触碰 localStorage、不改 `SAVE_VERSION`。
- `src/ui/CodexScreen.tsx` + `src/ui/codex.css`：图鉴覆盖层，两栏——
  - **结局图鉴**：列出全部 `DEATHS`；已发现显示标题 + 正文 + `AssetFrame(ending-${id})` 插画，未发现显示「？？？ 未发现」（走占位，不白屏）。
  - **成就**：列出 `achievementsFor(save)`，已解锁显示描述、未解锁显示「未解锁」。
  - 右上「关闭」按钮（调用 `onClose`），关闭后回到游戏 / 结局页。
- 入口接线：
  - `src/ui/ReignGame.tsx`：顶部新增「图鉴」按钮，点击开 `CodexScreen` 覆盖层（传入 `save`）。
  - `src/ui/EndingScreen.tsx`：新增可选 `onShowCodex` 回调，渲染「查看图鉴」按钮。
  - `src/App.tsx`：把 `save` 透传给 `ReignGame`，并把「查看图鉴」接到 `CodexScreen`。
