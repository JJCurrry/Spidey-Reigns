# T-007 · 内容扩充（M4-A：章鱼博士 / 猎人克莱文 / 号角日报）

> 里程碑：M4-A（内容扩充）｜ 触发：2026-09-03 用户裁决「M4 方向 = 内容扩充」
> 关联：接力文件第 96–113 行、原则 3 / 原则 7 / 不变量 #3 / #4 / #5 / #6、体检报告 2026-09-03

## 背景（为什么做）

M3 收口后卡池 57 张、8 边界 + 6 特殊死法，四分支平衡已达标（29.4 / 22.4 / 25.0 / 23.3）。
但单局内容偏「通用事件 + 已有角色（绿魔/金并/毒液/MJ）」，**专属剧情线稀薄**：
- 章鱼博士仅 1 张（`card-doc-ock-breakout`），无收尾、无特殊死法；
- 号角日报（詹姆森）仅 2 张（`card-jjj-headline` / `card-daily-bugle-scoop`），媒体线叙事空间没打开；
- 猎人克莱文（Kraven）**完全缺席**，是个可低成本引入的高辨识度反派。

用户裁决走「内容扩充」方向，目标：拉长单局新鲜度与重玩价值，且不破坏已达标的平衡。

## 范围（做什么）

仅动内容层 `src/content/`：

1. **新增 3 个特殊死法**（`deaths.ts`）：
   - `death-bugle-canceled`（社会性死亡：被号角日报全网抹黑到无人信你）
   - `death-ock-assimilated`（被章鱼博士机械臂同化/接管身体）
   - `death-kraven-hunt`（被克莱文猎杀并制成标本）
   - 文案原创、id kebab-case、不与现有 14 个结局撞名。
2. **新增约 18 张剧情线卡**（`cards.ts`，卡池 57 → 75+）：
   - **号角日报线（媒体主题）**：`card-bugle-smear` / `card-bugle-interview` / `card-bugle-leak` /
     `card-bugle-podcast` / `card-bugle-truth` / `card-bugle-crusade`（右选项触发 `death-bugle-canceled`）—— 6 张。
   - **章鱼博士线（反派主题，扩容）**：`card-doc-ock-tentacle` / `card-doc-ock-offer` /
     `card-doc-ock-research` / `card-doc-ock-lab-accident` / `card-doc-ock-redemption` /
     `card-doc-ock-finale`（右选项触发 `death-ock-assimilated`）—— 6 张。
   - **猎人克莱文线（反派主题，新建）**：`card-kraven-arrival` / `card-kraven-game` /
     `card-kraven-trap` / `card-kraven-respect` / `card-kraven-jungle` /
     `card-kraven-finale`（右选项触发 `death-kraven-hunt`）—— 6 张。
   - 三张 finale 卡各用 `once: true`，且触发侧之外另一侧为常规数值（非必死）。
3. **解锁档位**（`unlocks.ts`）：新卡归入 `tier-1`（minDeaths:1）、`tier-2`（minDeaths:2）、
   `tier-3`（minDeaths:3）现有档位，保持「每张恰好一档、tier-0 含兜底卡 `card-quiet-night`」守卫。
   - 号角日报线 → tier-1；章鱼博士线 → tier-2；克莱文线 → tier-3（晚期登场，符合反派登场节奏）。

## 不做（范围外）

- 不动 `src/core/` 任何逻辑、不改数值钳制（严守**原则 7**：死亡是设计内容，不削弱判定）。
- 不删减任何现有结局 / 卡牌（8 边界 + 现有 6 特殊齐全，不变量 #3 钳制机制不变）。
- 不引入新指标、不改四指标语义（ADR-0008）。
- 美术资源（AI 图）、音效、滑动动画、移动端适配——属 M4-B 体验打磨，另行开单。
- 部署发布配置——属 M4-C，另行开单；本单只做内容。

## 平衡迭代记录

（按 T-006 同法：每次改完跑 `--quick`，40s 一轮，调数值至达标，附交叉验证。）

- **初始设计**：号角日报线 6 张（媒体向）+ 章鱼博士线 6 张（反派向）+ 克莱文线 6 张（反派向），卡池 57→75。
- **试 A（初版）**：新卡把市民/反派「往上推」偏多 → 市民 31.4% / 媒体 19.0% / 反派 27.3% / 生活 22.3%，
  但 `death-civilians-min` 跌到 **1.9%**（死内容）、`death-villains-min` 2.8%。根因：反派线的「救市民」选项
  把市民往上推，抬了 `civilians-max`、压垮了 min 端。
- **试 B（反向选项改下推）**：bugle 线市民改下推、反派线反向选项 -6→-10 → 市民 24.5 / 媒体 20.0 /
  反派 30.2 / 生活 25.3，`death-civilians-min` 仅回升到 2.6%，仍不达标。
- **试 C（终值）**：反派线里 incidental 的「市民+」效果（tentacle/lab-accident/redemption/finale 等）改为下推，
  反派正向推动 +8→+6（压低越界风险）→ **市民 21.2 / 媒体 22.9 / 反派 27.7 / 生活 28.2**，
  八边界全部 ≥4.5%，交叉验证稳定。定为终值。
- **教训（与 T-006 一致）**：新增「英雄救市民/推反派」叙事时，其效果方向会无意识抬高对应指标的 max 端、
  压垮 min 端；须显式用反向选项与 cornered 卡保双端分布。
