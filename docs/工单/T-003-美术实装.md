# 任务工单：T-003 美术实装（M2）

> 灵魂是「ADR-0005 真图入库 + 不硬编码路径 + 缺失自动占位」。
> 检验标准：一个全新 AI 会话，只读 `CLAUDE.md` + 本工单 + `docs/接力文件.md`，能准确接着干 M3。

## 委托级别

- [x] **中委托**，按里程碑分批交付、每批一个 commit。理由：
  - 高委托的部分：图片生成、清单登记、组件接入、测试更新（可机器核对，全部可逆）。
  - 需人过目的部分：美术风格与手感（原则 3），AI 不自行「优化」；本单只按已裁决的 Reigns 式羊皮纸手绘质感执行。
- 中断条件（触发即停手报告，不自裁）：累计改动 >5 个非预期文件 / 想注释或删断言 /
  同一错误修 3 次 / 需要新增资源种类（如音效）/ 与 ADR-0007/#8 的 IP 边界冲突。

## 验收分级

- **A 级（机器判定）**：类型、lint、测试、覆盖率、构建、所有 asset id 可解析、缺失时自动占位。
- **B 级（人判定，AI 不自评）**：美术风格是否统一、是否符合 Reigns 式质感、视觉是否舒服。

## 自动化级别

- [x] **L1 自动 PR**：生成后由人审一次再合入。不触碰认证 / 支付 / 生产 / 远端发布。
- ❌ 推送到公开远端属 **L3，仅由人执行**（ADR-0007）。

## 入（前提 / 背景）

- 前提：M1 垂直切片已完成，`npm run verify` 全绿，占位层 `AssetFrame` 与 `assets.ts` 已就位。
- 目标：用 AI 生成原创美术填充 `public/assets/`，在 `assets.ts` 登记，并让 `AssetFrame` 自动切换为真图。
- 人在开工前的裁决：
  1. **美术范围** → 完整 M2：4 指标图标 + 15 张角色立绘（具名说话者）+ 11 张结局插画。
  2. **风格** → 已裁决 Reigns 式羊皮纸手绘质感（parchment / ink / woodcut / 低饱和）。
  3. **IP 边界** → 仅允许 AI 生成的原创演绎，禁止漫威官方素材（剧照/海报/商标/logo/官方字体）。

## 范围边界（In scope）

1. `public/assets/character/`：15 张具名说话者立绘。
2. `public/assets/icon/`：4 张指标图标（市民 / 媒体 / 反派 / 私人生活）。
3. `public/assets/ending/`：11 张死亡结局插画。
4. `src/content/assets.ts`：登记全部 30 条资源（id / path / kind / note），note 必须标注 AI 生成日期与原创声明。
5. `src/ui/EndingScreen.tsx`：接入 `AssetFrame` 展示结局插画（`ending-${death.id}`）。
6. `src/ui/AssetFrame.test.tsx`：更新断言，反映清单已填充，同时保留「未登记 id 降级占位」的守卫。
7. `docs/接力文件.md` + `docs/地图.md`：同步 M2 进度与结构变化。

## Out of scope（与目标同等重要）

- ❌ 数值 / 手感 / 文案调参 —— 属原则 3，需新工单。
- ❌ 音效 / 动画曲线 / 震动 / 粒子特效。
- ❌ 生成「主角战衣全身像」等当前 UI 未引用的资源。
- ❌ 上架 / 部署 / 推送到公开远端。
- ❌ 漫威官方素材、剧照、商标、logo、官方字体。
- ❌ 削弱或缓冲死亡判定（原则 7）。

## 假设与默认值（人已逐项核对；代码内用 `ASSUMPTION-<ID>` 标记）

- `ASSUMPTION-ART-STYLE`：**Reigns 式羊皮纸手绘质感**（parchment / ink / woodcut / 低饱和）。
  依据：M1 视觉风格已裁决；本单只按此执行，不自行切换风格。
- `ASSUMPTION-IP-BOUNDARY`：**AI 生成的原创演绎允许入库；漫威官方素材禁止**。
  依据：ADR-0007 / 不变量 #8；每张资源 note 必须声明原创。
- `ASSUMPTION-ABSTRACT-SPEAKERS`：**5 个抽象说话者（警用频段 / 广场标语 / 医院来电 / 手写信 / 涂鸦）保留程序化占位**。
  依据：本次 M2 范围限定为 15 个具名角色，抽象源走占位不违和。
- `ASSUMPTION-HERO-PORTRAIT`：**额外登记 `char-spider-man`（荷兰弟 / MCU 式主角战衣半身像，+1 张）**，当前 UI 未引用，预留给未来的标题 / 头像槽。
  依据：用户明确要求「蜘蛛侠要荷兰弟版本」；结局插画中的主角亦统一按此气质生成。属对原「30 张、无未引用资源」计划的轻微越界（reversible），已登记、已声明原创（ADR-0009），不触碰红线。
