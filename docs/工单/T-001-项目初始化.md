## 验收分级
- [x] **A 级**：全部机器可执行（`npm run verify` 全绿即过，无需人肉判断）。

## 自动化级别
- [x] **L1 自动 PR**：生成后由人审一次再合入。理由：涉及 CI 与钩子配置，需人过目一次；
      但不触碰认证 / 支付 / 生产 / 数据 schema 等 L3 范围。

## 入（前提 / 背景）
- 目标：把空仓库初始化为「可被 AI 会话接力开发」的状态——制品七件套就位、工程四道门可跑、
  并有一个最小真实的玩法参考实现供后续高委托复制。
- 范围边界（In scope）：
  1. 制品七件套：`CLAUDE.md`（唯一根）+ `docs/地图.md` + `docs/不变量.md` + `docs/术语表.md`
     + `docs/接力文件.md` + 本工单 + `docs/adr/ADR-0001~0006`。
  2. 工程四道门：TypeScript strict、ESLint 9（含 `src/core` 纯净性规则）、Prettier、
     Vitest（node 环境 + 覆盖率棘轮）、husky pre-commit、GitHub Actions CI。
  3. 参考实现：`src/core/` 的 types / rng / stats / deck / game + `src/content/` 的
     常量、6 张种子卡、8 种死亡结局。
  4. 单元测试：随机可重现、指标钳制、抽卡去重与兜底、内容完整性守卫、完整一局模拟。
- **Out of scope（与目标同等重要）**：

  - ❌ 存档系统（localStorage 读写、版本迁移）——属于 M2；本单只定义 `SAVE_VERSION` 常量。
  - ❌ 美术资源生产与 `src/content/assets.ts` 清单填充——属于 M1（见 ADR-0005）。
  - ❌ 任何部署 / 发布动作——见 ADR-0006，先问人。

## 假设与默认值（AI 计划里列出，人逐项核对；代码内用 `ASSUMPTION-<ID>` 标记）
- `ASSUMPTION-STAT-MAP`：四指标 = 市民 / 声誉 / 秩序 / 生活，初始值均 50，任一触 0 或 100 即结束一局。
  依据：Reigns 原作四指标结构 + 蜘蛛侠叙事（市民安全 / 媒体形象 / 街头秩序 / 私人生活）。
- `ASSUMPTION-DEATH-8`：M0 先定义 8 种结局（四指标各触底 / 爆表各一）。依据：不变量 #6 需要兜底，
  且四指标双向致死是 Reigns 的核心张力来源。
- 默认值：每回合抽 1 张卡；无「回合上限」，一局只因死亡结束。
