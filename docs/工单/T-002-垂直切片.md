# 任务工单：T-002 垂直切片（M1：端到端可玩）

> 灵魂是「一入一出 + 前提条件」。
> 检验标准：一个全新 AI 会话，只读 `CLAUDE.md` + 本工单 + `docs/接力文件.md`，能准确接着干 M2。

## 委托级别
- [x] **中委托**，按里程碑分批交付、每批一个 commit。理由：
  - 高委托的部分：纯逻辑层改造、测试、内容扩充（可 100% 机器判定，且全部可逆）。
  - 需人过目的部分：玩法手感（数值曲线 / 死法节奏 / 文案语气）与视觉风格
    —— 属 `CLAUDE.md` 原则 3，AI 不得自行「优化」，改动需新开工单。
- 中断条件（触发即停手报告，不自裁）：累计改动 >5 个非预期文件 / 想注释或删断言 /
  同一错误修 3 次 / 需要改 `STAT_KEYS` 的顺序或新增指标键（需新 ADR）。

## 验收分级
- **A 级（机器判定）**：类型、lint、测试、覆盖率、构建、完整一局可跑通。
- **B 级（人判定，AI 不自评）**：手感是否对、文案是否够味、死法节奏是否合适。

## 自动化级别
- [x] **L1 自动 PR**：生成后由人审一次再合入。不触碰认证 / 支付 / 生产 / 远端发布。
- ❌ 推送到公开远端属 **L3，仅由人执行**（ADR-0007）。

## 入（前提 / 背景）
- 前提：M0 已完成（`fb59556`），四道门全绿，核心玩法纯逻辑参考实现可跑完整一局。
- 目标：跑通**端到端可玩的垂直切片**（ADR-0002）：滑卡 → 四指标反馈 → 死于边界 → 结局页 → 再来一局。

  2. **解锁进度** → **M1 就带**：死亡累积解锁新卡。
  3. **美术** → **M1 只做占位层**（CSS/SVG 程序化占位），不产出位图。
  4. **视觉风格** → **Reigns 式中世纪手绘质感**（羊皮纸 / 细线木刻 / 低饱和）。

### Out of scope（与目标同等重要）

- ❌ 音效 / 动画曲线精调 / 震动反馈。
- ❌ 平衡数值的系统性调优（M2；本单只保证「能玩完且不卡死」）。
- ❌ 多角色切换（Reigns 的换国王）—— M2 及以后。
- ❌ 任何部署 / 推送动作。
- ❌ 削弱或缓冲死亡判定（原则 7）—— 包括给指标加「临界保护」。

## 假设与默认值（人已逐项核对；代码内用 `ASSUMPTION-<ID>` 标记）
- `ASSUMPTION-VILLAIN-DIR`：**反派高 = 反派猖獗，低 = 反派被压制**，两端都致命。
  依据：ADR-0008；**用户已确认四元组，方向定义由 ADR-0008 明确规定**。
- `ASSUMPTION-NO-NUMBER`：指标条**不显示具体数值**，只给趋势（Reigns 传统）。
  依据：Reigns 原作；**尚未经人确认**，若想看数字请新开工单。
- `ASSUMPTION-UNLOCK-TIER`：解锁按「累积死亡局数」分档，不做逐卡解锁。
  依据：实现成本可控 + 完整性可机器校验；**尚未经人确认**。
- 默认值：每回合抽 1 张卡；无回合上限，一局只因死亡结束。
