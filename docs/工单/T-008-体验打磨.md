# T-008 · 体验打磨（M4-B）

> 里程碑：M4-B ｜ 类型：表现层 / 不变量无关 ｜ 状态：待实施
> 前序：M4-A 内容扩充（T-007，卡池 57→75，平衡达标）已完成并提交。

## 目标

把「能玩」提升到「手感顺、移动端可用、首屏快」的成品状态。纯表现层改动，
**不触碰任何玩法数值、卡牌内容、core 逻辑**（严守不变量 #4「内容只放 src/content」、
原则 7「死亡是设计内容、不削弱判定」、不变量 #7「src/core 禁 React/浏览器全局」）。

## 范围

1. **翻卡过渡**
   - 选卡后旧卡沿「抉择方向」飞出（向左选→向左飞、向右选→向右飞），淡出+旋转。
   - 新卡淡入上滑入场（keyframe）。
   - 结局页缩放淡入。
   - 飞出动画**只放在指针拖拽释放路径**；键盘 `←/→` 路径保持 `onChoose` 同步调用，
     不引入任何延迟（验收：`ReignGame.test.tsx` 键盘同步抉择必须仍过）。
2. **音效 + 震动 + 静音开关**
   - 音效走 **Web Audio API 程序化合成**（oscillator + 增益包络），**不新增任何音频素材文件**
     （规避 ADR-0007 的漫威素材红线、零加载成本）。
   - 三种音：选卡「咻」（短促下滑扫频）、死亡「咚」（低频闷响）、指标进入临界（≤10 或 ≥90）轻提示音。
   - 震动：`navigator.vibrate`，特性探测后调用；选卡轻震、死亡震动序列。
   - 静音开关：顶栏 + 标题屏各一个，状态持久化到 `localStorage['sr.muted']`，默认未静音、即时生效。
   - 静音同时关闭音效与震动（单一开关）。
3. **移动端竖屏适配**
   - `100dvh` 满高（替代 `100vh` 在移动端的视口跳动）。
   - `env(safe-area-inset-*)` 安全区内边距（刘海/圆角屏）。
   - `overscroll-behavior: none` 禁下拉刷新/橡皮筋。
   - `index.html` 视口加 `viewport-fit=cover`。
4. **首屏加载优化**
   - `CodexScreen` 改为 `React.lazy` 懒加载（仅点开图鉴才拉取），从首屏 bundle 拆出独立 chunk。
   - `Suspense` 兜底（加载中占位）。

## 不做（范围外）

- 不改 `src/core/`、`src/content/`（卡牌/死法/解锁）任何逻辑与数值。
- 不引入第三方动画库 / 音频库（保持零依赖，纯 CSS + Web Audio）。
- 不做账号系统、云存档、多人。

## 验收（可验收，机器优先）

- `npm run verify` 全绿（类型 + lint + 测试；现有 79 测试 + 可能新增的飞出/静音测试）。
- **键盘同步不阻塞**：`ReignGame.test.tsx`「按右方向键触发抉择、指标随之变化」仍过
  （证明飞出动画未把 onChoose 延迟到异步）。
- **App 冒烟仍过**：`App.test.tsx` 标题→开始→四指标条+事件卡+滑动区。
- **静音持久化**：切换后 `localStorage['sr.muted']` 写入 `'1'`/`'0'`；刷新后保持；默认未静音。
- **首屏不含 codex**：`npm run build` 成功且 `dist/assets/` 出现 codex 独立 chunk
  （首屏主包不内含 CodexScreen 代码）。
- **无障碍降级**：`@media (prefers-reduced-motion: reduce)` 下关闭翻卡/入场/结局过渡动画。
- **零素材红线**：仓库 `public/`、源码目录不新增任何音频文件；音效全为运行时合成。
- 平衡不受影响：本改动不改卡牌/数值，`scripts/balance-audit.ts` 分布应与原 T-007 基线一致
  （仅作确认，不要求重新调参）。

## 实测记录（实施完成，2026-09-03）

- **`npm run verify` 全绿**：13 测试文件 / 79 测试通过（含原 ReignGame / App / TitleScreen 冒烟）。
- **键盘同步不阻塞**：`ReignGame.test.tsx`「按右方向键触发抉择、指标随之变化」仍过——
  飞出动画只放在指针释放路径，`onChoose` 在键盘路径保持同步调用（未引入延迟）。
- **App 冒烟仍过**：标题→开始→四指标条+事件卡+滑动区。
- **静音持久化**：`localStorage['sr.muted']` 写入 `'1'`/`'0'`；`useMuted` 订阅，默认未静音、即时生效。
- **首屏不含 codex**：`npm run build` 成功，`CodexScreen` 拆为独立 chunk
  （`dist/assets/CodexScreen-*.js` 3.19 kB + `*.css` 2.35 kB），首屏主包 `index-*.js` 不再内联图鉴代码。
- **无障碍降级**：`global.css` 加 `@media (prefers-reduced-motion: reduce)` 关闭翻卡/入场/结局过渡。
- **零素材红线**：`src/ui/audio.ts` 全为 Web Audio 运行时合成，仓库未新增任何音频文件。
- **平衡未受影响**：`balance-audit.ts --quick` 四分支 21.2% / 22.9% / 27.7% / 28.2% 与 T-007 基线一致，八边界全部 ≥4.5%。
- **踩坑（供后续）**：
  - 给 `SwipeArea` 加 `key={card.id}` 会使其每次重挂载、滑动区 DOM 节点被替换，破坏
    「按方向键循环抉择」类测试（测试捕获旧节点后对其发事件无效）。改法：把 `key` 移到内层
    `.card-enter` 包裹层，滑动区节点保持稳定，入场动画照常触发。
  - `CodexScreen` 改 `React.lazy` 后，对话框异步出现，测试须用 `findByRole` 等待（原 `getByRole` 同步断言会失败）。
