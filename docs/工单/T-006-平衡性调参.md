# T-006 · 四分支死法平衡调参

> 里程碑：M3-A（内容与平衡性）｜ 触发：2026-09-02 用户给出调参规格
> 关联：体检报告 `平衡体检报告-2026-08-31.md`、接力文件第 82 行、原则 3 / 原则 7 / 不变量 #3

## 背景（为什么做）

平衡体检（4000 局 random）显示：八条边界结局里，张力几乎全压在**市民 + 私人生活**两条线
（合计 ~90.8% 边界死亡），而**媒体 + 反派**四条边界仅 ~9.2%——其中 `death-media-min` 0.9%、
`death-villains-min` 0.1%、`death-civilians-min` 0.1% 近乎死内容；`death-civilians-max` 单条占 42.5%。
用户判定此偏科严重，要求**四个分支相对平衡**。

根因（来自体检与代码核对）：
- 媒体 / 反派 缺"临界放大器卡"——没有像 `card-civilians-worship`（市民≥85 还 +6）那样在极端值附近
  继续同向推的卡，所以无论高低都回中，两端都死不成。
- `card-civilians-worship` 右选项 ` civilians:+6` 形成冲顶正反馈，`civilians-min` 又没有任何放大器 →
  市民 99.9% 死在"被供上神坛"，几乎不见"被驱逐"。
- 私人生活线已是最简健康态（min 9.6% / max 7.4%），本轮**不做破坏性改动**，只作为对照基准。

## 范围（做什么）

仅改内容层 `src/content/cards.ts`（新增 5 张临界放大器卡 + 削弱 1 张冲顶反馈），不改引擎、
不改 `deaths.ts`、不改数值钳制。

新增卡（均为条件触发，贴近边界时给叙事与数值双重预告）：
1. `card-media-stardom`：media≥68 ⇒ 冲顶（media+12 / 回复 media-10）
2. `card-media-silence`：media≤32 ⇒ 触底（media-14 / 回复 media+10）
3. `card-villain-overlord`：villains≥68 ⇒ 冲顶（villains+12 / 回复 villains-10）
4. `card-villain-vacuum`：villains≤32 ⇒ 触底（villains-14 / 回复 villains+10）
5. `card-civilians-exodus`：civilians≤32 ⇒ 触底（civilians-14 / 回复 civilians+10）

削弱：`card-civilians-worship` 右选项 `civilians:6→2`（降低冲顶正反馈，让市民线 min/max 双向都可死）。

unlocks.ts：5 张新卡归入 tier-1（minDeaths:1），保持"每张恰好一档、tier-0 含兜底卡"守卫。

## 不做（范围外）

- 不动 `src/core/` 任何逻辑、不动 `deaths.ts` 死亡判定（严守**原则 7**：死亡是设计内容，不削弱判定）。
- 不删减任何结局（8 边界 + 6 特殊齐全，不变量 #3 钳制机制不变）。
- 不对私人生活线做破坏性调参（保持其健康双端分布）。
  - **第二轮修订**：首轮调参的副作用是私人生活被压到 16.3%（低于目标 18%），
    故第二轮**转为给它加两张与媒体/反派同构的临界放大器**（此前「不做」是因为它原本是健康基准线，
    首轮后被打破，故按「以复跑数据为准」条款纳入范围）。
- 文案语气、美术资源、解锁节奏之外的玩法变更——另行开单。

## 第二轮调参（2026-09-03，验收全部达标）

首轮后四项为 31.8% / 26.1% / 25.8% / 16.3%，市民与生活仍落在目标区间外。第二轮改动（仍只动 `src/content/`）：

| 卡 | 改动 | 意图 |
| --- | --- | --- |
| `card-life-domestic`（新增） | life ≥ 55，权重 2，左 `life+10/villains+3`、右 `life+7/media-3` | 抬高 `death-life-max` |
| `card-life-burnout`（新增） | life ≤ 45，权重 2，左 `life-10/media+3`、右 `life-7/villains+4` | 抬高 `death-life-min` |
| `card-civilians-worship` | 右选项去掉 `civilians: +2`（只留 `media: +8`） | 消除冲顶正反馈的最后残留 |
| `card-villain-vacuum` | 权重 3 → 4 | 抬高 `death-villains-min` |
| `card-civilians-exodus` | 权重 4 → 5 | 抬高 `death-civilians-min` |

迭代过程（每次改完跑 `--quick` 快速模式，40s 一轮）：
- **试 A**：两张生活放大器先用「权重 3 / 力度 14·10」（与媒体/反派对齐）→ 生活冲到 **36.3%**，严重过头。
  教训：生活是静态被推动频率最高的指标（76% 的选项都碰它），同样的放大器在它身上的边际效应远大于媒体/反派。
- **试 B**：减半为「权重 2 / 力度 10·7」→ 27.5 / 24.2 / 24.2 / 24.1，四项首次全部进区间。
- **试 C**：再加 min 端权重调整 → **29.4 / 22.4 / 25.0 / 23.3**，且三个 min 结局全部 ≥4.5%。定为终值。

工具侧改进（本轮顺带，见 `scripts/balance-audit.ts`）：
- 新增 `--quick` 快速模式：只跑 random 4000 局，40s 出四分支 + 八边界占比，供调参快速往返。
- 新增 `SEED_OFFSET` 环境变量：换平行种子做抗过拟合交叉验证。
- 新增 `AUDIT_NOTE` 环境变量：把「本轮调了什么」写进报告头部。
- 修：报告生成时间由硬编码 `2026-09-02` 改为当天日期（输出文件名同步）；
  「结局总数」的边界/特殊数量、控制台与报告里的占比，改由实际数据算出并保留一位小数。
