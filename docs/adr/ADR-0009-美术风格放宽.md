# ADR-0009：美术风格放宽——允许 MCU / 荷兰弟式原创演绎（修订 ADR-0007 的 IP 硬线）

## 背景（Context）

M2 美术实装阶段，用户于 2026-08-31 明确裁决：放宽 `ADR-0007` / 不变量 #8 的「禁止漫威素材」硬线，
并希望主角蜘蛛侠呈现「荷兰弟（Tom Holland）/ MCU 时代」的观感。

按 `CLAUDE.md` 原则 2 与仲裁序，红线级冲突不自裁、停手上报交人裁决——
用户的本次裁决即正式的人裁决，本 ADR 将其落成记录，使不变量与仓库实际状态保持一致（而非让红线名存实亡）。

## 决定（Decision）

- 不变量 #8 的「硬线」放宽为：**允许 AI 生成 / 自绘的 MCU / 荷兰弟式原创演绎**；
  主角蜘蛛侠按 MCU / Tom Holland 时代的年轻英雄气质设计（红蓝战衣、年轻身形、都市夜景语境）。
- 仍保留一条更窄的**安全线**（公开仓库现实约束）：**不把漫威官方宣传物料**
  （官方剧照、海报、商标、logo、官方字体）写进仓库或构建产物。
  原因：本仓库是公开 GitHub 仓库（`JJCurrry/Spidey-Reigns`，`private:false`），
  传播官方版权素材存在下架 / 法律风险，且历史提交可被 fork / 镜像，删除不消除传播。
- 若用户日后坚持入库官方素材，须由其本人承担版权与下架风险，并建议走 `ADR-0006` 的原创化回归路径。
- AI 生成的「演绎」不构成对官方素材的复制，但仍应避免逐帧复刻具体官方剧照 / 海报构图。
- 本 ADR 记录在案后，后续会话按本 ADR 执行，不再以旧版 #8 劝阻；
  但每次入库新美术资源仍须对照不变量 #8 自检一次。

## 被否决的备选及原因（Alternatives considered）

- **继续严守旧版 #8，拒绝 MCU 风**：最安全，但与用户 2026-08-31 的明确裁决冲突，且用户为项目所有者，有权放宽。
- **直接把漫威官方剧照 / 海报写进公开仓库**：用户口头许可，但公仓库 + 官方版权素材 = 不可逆的下架 / 法律风险，
  超出「原创演绎」边界，本 AI 不代办此动作（用户可自行承担风险入库）。

## 后果（Consequences）

- 正面：美术可与用户期待的 MCU / 荷兰弟观感对齐，成品说服力提升。
- 负面：版权风险从「可控」变为「依赖原创演绎是否足够脱敏」；若被指擦边，回归路径仍是 `ADR-0006` 原创化。
- 后续要注意：新增美术资源入库前，仍过一遍不变量 #8 的自检（官方物料硬线是否触碰）。
