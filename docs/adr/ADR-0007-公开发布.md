# ADR-0007：公开发布（取代 ADR-0006）

## 背景（Context）

M0 收尾、准备把首个 commit 推到远端时，查 GitHub API 确认远端仓库
`https://github.com/JJCurrry/Spidey-Reigns.git` 是**公开仓库**（`"private": false`）。
这与 ADR-0006（个人练习、不公开发布）和不变量 #8 直接冲突。

按 `CLAUDE.md` 原则 2 与仲裁序的约定，遇到红线级冲突不自裁，停手上报交人裁决。
用户裁决：**不在意是否为私有仓库，公开发布**。

## 决定（Decision）

- 项目以**公开仓库**形式发布到 `https://github.com/JJCurrry/Spidey-Reigns.git`。
- ADR-0006 的「禁止进入任何公开地址」约束**解除**；不变量 #8 相应改写（见下）。
- 保留一条更窄但更硬的红线（不变量 #8 新版）：
  **禁止把漫威官方素材**（官方剧照、海报、商标、logo、官方字体）**放进仓库或构建产物**；
  仓库内只允许 AI 生成 / 自绘的原创演绎，以及文字层面的角色名。
- **风险由用户自担** —— 本 ADR 记录在案后，后续 AI 会话不再重复劝阻，
  但新增美术资源入库前仍须提醒对照不变量 #8 自检一次。

## 被否决的备选及原因（Alternatives considered）

- **把仓库改成 private 再推**：零风险、代码一行不用改，是本 AI 的首选方案。
  否决原因：用户明确选择不做。
- **先做原创化（换主角名与视觉标识）再公开**：保留《Reigns》玩法内核与「纽约街头英雄」
  的设定气质，剥离漫威 IP 元素。风险最低且可公开。
  否决原因：需要额外开改造工单，用户选择不做。
  **注意：这是回归路径** —— 若日后收到下架或侵权通知，应回到本方案并新开 ADR。

## 后果（Consequences）

- 正面：作品可公开分享、可进作品集、有远端备份与版本历史。
- 负面：侵权风险从「可控」变为**不可逆**；一旦外发，历史提交仍可能被他人 fork 或镜像，
  删除仓库不等于消除传播。
- 后续要注意：
  1. 任何美术资源入库前，先过一遍不变量 #8 的自检。
  2. 若要**上架应用商店或接入广告 / 商业化**，必须先执行 ADR-0006 描述的原创化，并新开 ADR。
  3. M1 引入资源管线（`src/content/assets.ts`）时，把不变量 #8 下沉为 L1：
     在 CI 中校验产物与仓库不含受限素材目录（`public/assets/_official/`）。
