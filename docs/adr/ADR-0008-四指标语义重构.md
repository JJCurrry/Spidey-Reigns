# ADR-0008：四指标改为 市民 / 媒体 / 反派 / 私人生活

## 背景（Context）

M0 的四指标（市民 / 声誉 / 秩序 / 生活）是 AI 按 Reigns 原作结构 + 蜘蛛侠叙事推出来的，
标记为 `ASSUMPTION-STAT-MAP`，**未经人逐项确认**（见 `docs/接力文件.md`「待人类裁决的问题」）。

在 M1 开工前请人裁决，用户选择换成 **市民 / 媒体 / 反派 / 私人生活**。
这条改动触及 `src/core/types.ts` 的 `STAT_KEYS`——按 `docs/地图.md` 的约定，
「改这里等于改全仓，需走 ADR」，故立本 ADR 记录意图与代价。

同时它推翻了 M0 的一个隐性设计前提：M0 的四元组里有三个是「主角的能力维度」
（声誉 / 秩序），只有「生活」是对内的；新四元组里**「反派」是一个敌对维度的势力值**，
语义方向需要明确定义（见下）。

## 决定（Decision）

四指标键定为：

| 键 | 展示名 | 语义（双向，两端都致命） |
|---|---|---|
| `civilians` | 市民 | 市民对你的需要与信任。0 = 被驱逐（不再需要你）；100 = 被供上神坛（你成了城市的日程表） |
| `media` | 媒体 | 媒体对你的叙事权。0 = 被抹去（你说什么都不再有人报道）；100 = 被消费（你成了镜头里的角色） |
| `villains` | 反派 | 反派势力的猖獗程度。0 = 你把反派清空（城市开始把你当成下一个威胁）；100 = 反派横行（街区被分完） |
| `life` | 私人生活 | 彼得·帕克这个人的存活度。0 = 彼得·帕克消失了；100 = 战衣挂进衣柜（你不再出门） |

- 初始值仍为 **50**，边界仍为 **0 / 100**，**双向致死语义不变**（不变量 #3、原则 7）。
- 边界结局 id 的硬约定 `death-<指标键>-<min|max>` 不变，但 8 个结局的**文案全部重写**，
  因为 `reputation` / `order` 对应的文案已随指标语义失效。
- 展示顺序 = `STAT_KEYS` 数组顺序，UI 按此渲染，不另设顺序常量。

### 关于「反派」这一维的方向定义

`villains` 高 = 反派猖獗，低 = 反派被压制。这意味着**玩家会频繁想把它打到 0**，
而 0 同样是死——这是本作最锋利的一处张力，也是最容易让玩家困惑的一处。
对策放在内容侧而非引擎侧：给 `villains` 接近两端时的卡牌各写一批专属条件卡
（低值触发「城市开始怕你」，高值触发「地盘被分完」），让玩家在触界前先看到叙事预告。
**引擎不做任何「临界缓冲」**（那违反原则 7）。

## 被否决的备选及原因（Alternatives considered）

- **保留 M0 四元组，只在展示层改名**：改 `STAT_LABELS` 即可，成本几乎为零。
  否决原因：用户明确选了新语义，而「反派」不只是旧「秩序」的换皮——
  它是一个方向相反的量（秩序高 = 好，反派高 = 坏）。展示层改名会让代码里的
  `order: +8` 与屏幕上显示的「反派 +8」互相矛盾，是比重命名更贵的债。
- **换成 市民 / 声望 / 秩序 / 生活 的微调版**：否决原因：用户已裁决。
- **先玩过垂直切片再定（选项 C）**：否决原因：用户选择现在就定（选项 B），
  且 40 张卡的文案若按旧指标写完再改，返工量远大于现在改。

## 后果（Consequences）

- 正面：四元组全部对齐到「外部三方势力 + 一个私人自我」的 Reigns 结构，
  每个维度都有清晰的两端叙事；40 张卡可以围绕这四个势力直接展开。
- 负面：M0 写好的 8 个边界结局文案全部作废需重写；种子卡的 effect 键名全改；
  5 个测试文件的用例数据全部要更新。这是**已知且已接受的返工**。
- 后续要注意：**任何新增指标键都必须先走 ADR**，本 ADR 即是先例。
  `STAT_KEYS` 的顺序 = UI 顺序，重排等于改界面布局，同样按 ADR 处理。
