# ADR-0006：IP 边界 —— 个人练习，不公开发布

## 背景（Context）

本项目以蜘蛛侠（Spider-Man）为主角形象。蜘蛛侠及相关角色名、视觉标识是漫威 / 索尼的受保护 IP。
同人非商用作品在多数法域仍处于灰色地带，而**公开发布、放进作品集、上架或任何形式的传播**
会显著提高侵权风险——且一旦外发即不可逆。

这不是要不要"小心"的问题，而是要在工程上把边界固化下来，让每个后续 AI 会话都不会误踩。

## 决定（Decision）

- 项目定位：**个人练习 / 自娱，不公开发布**。
- 蜘蛛侠相关美术与角色名资源**仅限本地开发与本地试玩**，禁止进入：
  可公开访问的部署产物、CDN、公开仓库、任何分享链接、截屏传播。
- 此约束写入不变量 #8，并在 `CLAUDE.md` 原则 8 / 9 中重复强调（双读者：人与 AI 都要看见）。
- 若未来要公开发布，必须先执行**原创化**：自创主角名与视觉标识，保留《Reigns》玩法内核
  与"纽约街头英雄"的设定气质，剥离所有漫威 IP 元素——并新开 ADR 记录该转向。

## 被否决的备选及原因（Alternatives considered）

- **直接公开发布，赌不被告**：省事。
  否决原因：风险不可控且不可逆；一旦收到下架或侵权通知，作品与声誉同时受损。
- **一开始就做完全原创角色，不碰蜘蛛侠**：风险为零。
  否决原因：用户明确希望以蜘蛛侠为主角形象，这是本项目的乐趣来源；在"不公开发布"的前提下风险自担且可控。
- **公开发布但自称同人非商用**：部分法域有豁免传统。
  否决原因：豁免边界因法域而异，且商业化平台（应用商店 / 广告）一旦介入即失效，判断成本高、收益低。

## 后果（Consequences）

- 正面：在保留创作乐趣的前提下，把法律风险压到最低；边界写进工程制品，不依赖记忆。
- 负面：作品无法公开分享与展示，作品集价值受限；CI / 部署相关动作需要人工把关。
- 后续要注意：**任何涉及部署、打包分发、上传、生成分享链接的操作都必须先问人**——
  这条已写进 `CLAUDE.md` 原则 8。不变量 #8 目前是"待证据式核对"，
  一旦出现部署脚本，必须同步升为 L1 自动检查（例如在 CI 中校验产物不含受限资源目录）。
