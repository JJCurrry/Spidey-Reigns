# 不变量清单（红线 · Invariants）

> 不变量 = 任何改动前后都必须为真的性质。违反后果是「事故」（存档丢失 / 数值失控 / 局卡死 / IP 外泄）。
> 只装「出事」的，不装「难看」的（难看的归 lint）。全局 ≤20 条；格式：对象 + 必须/禁止 + 可判定 + 原因。
> 可机器判定的已下沉为 ESLint 规则或 Vitest 守卫（见「下沉状态」列），清单只留证据式核对的条目。

## 模块级不变量（按需、从严）

- `src/core/`：所有导出函数必须是纯函数或只依赖入参注入的依赖（如 `Rng`）；禁止模块级可变全局状态。
  —— 原因：一局的可重现性依赖「无隐藏状态」。—— 证据：`src/core/rng.ts:1`、`src/core/game.ts:1`
- `src/content/`：新增卡牌必须同时提供出现条件或默认权重，禁止无条件的无限重复卡（除非显式标 `once: false` 且为兜底）。
  —— 原因：无权重控制的卡会淹没牌池，稀释剧情节奏。—— 证据：`src/content/cards.ts:1`
