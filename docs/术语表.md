# 术语表（Glossary · 共识层）

> 只收「望文生义会错」的词——与主流一致的词一律不收。相同的不写，不同的才写；越短越有用。
> 写工单 / 计划 / 代码注释时，凡涉及下表术语，显式点名相关词条，避免双向静默填空。

| 术语 | 本项目含义 | 地雷（与主流默认的差异） | 出处 |
|---|---|---|---|
| 指标（Stat） | 四个恒为 0–100 的整数：市民 / 声誉 / 秩序 / 生活。任一触及 **0 或 100 都立即结束一局**。 | 主流直觉是「角色属性」或「血条」（越高越好）。本项目是**双向倒计时**，满值和空值同样致命。 | 不变量 #3 |
| 卡牌（Card） | 一个事件 + 左右两个选项。**抽完即弃，不构成手牌**，玩家不可持有、不可组合。 | 主流卡牌游戏里 Card 是手牌资源、可组合成牌组。本项目 Card 只是一次性事件。 | ADR-0003 |
| 牌局（Reign） | 从开始到死亡的一次完整流程（一次「统治」）。玩家的一局游戏。 | 易被理解成「一局对战」或「一个回合」。Reigns 原作术语，本项目沿用。 | ADR-0003 |
| 选项（Choice） | 卡牌的左分支或右分支，包含文案 + 效果（+ 可选后继标记 / 立即死亡）。 | 易被当成纯文案。本项目 Choice **必须带效果**，否则违反不变量 #5。 | 不变量 #5 |
| 效果（Effect） | 对四个指标的一次性整数增减（delta）。**不是 Buff / Debuff，无持续时间**。 | 主流里 Effect 常指带时长的状态。本项目 Effect 是一次性的、立即结算。 | 不变量 #3 |
| 条件（Condition） | 卡牌**能否出现**的前置判定（指标区间 / 已有标记 / 最少回合数 `minTurn`）。 | 极易与「权重」混淆：Condition 是布尔门禁，不是概率。 | ADR-0003 |
| 权重（Weight） | 在同一批通过 Condition 的候选卡之间，决定被抽中的**相对概率**。 | 与 Condition 是两回事：先过条件，再按权重抽。 | ADR-0003 |
| 死亡（Death） | 一局的结束，产出结局文案。**是内容，不是失败惩罚**；死亡累积驱动后续解锁。 | 主流里死亡 = 失败、需要重试。本项目死亡是预期且被设计的终点。 | CLAUDE.md 原则 7 |
| 种子（Seed） | 一局随机流的来源。同种子 + 同操作序列 = 完全相同的牌序。玩家不可见，仅调试与测试用。 | 易被当成「随机难度」。它是可重现性的保证，不是难度调节。 | 不变量 #1 |
| 标记（Flag） | 局内的字符串状态位，由选项写入，供后续 Condition 判定（如「已得罪号角日报」）。 | 易与「成就 / 解锁」混淆。Flag 是**局内**状态，局终即清空。 | ADR-0003 |
